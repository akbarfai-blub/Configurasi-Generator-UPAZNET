## Design Specificity Verdict

### LLM Assessment
Aplikasi ini memiliki identitas visual operasional yang sangat kuat dan terarah: palet **Terminal Navy** (`#003C71`) dan **Signal Green** (`#00A651`) memberikan atmosfer teknikal "Ops Console" yang otentik bagi tim Helpdesk/NOC Upaznet. Kontras antara meja kerja terang (*light desk*) dengan panel gelap (*dark deck*) secara jelas memisahkan area input operator dengan area keluaran mesin/terminal. Namun, spesifisitas desain ini belum sepenuhnya matang di sisi ergonomi operasional: layout runtuh terlalu agresif pada layar laptop (<1280px), status visual ikon terlalu dini menyatakan sukses pada panel kosong, dan perintah Command Hub belum terkelompok secara taktis menurut urgensi penanganan gangguan.

## What's Working
1. **Dua Panel Skrip Berbobot Simetris**: Pemisahan tegas panel ZTE OLT dan MikroTik PPPoE dengan bobot visual identik mencegah kesalahan fatal teknisi menempelkan konfigurasi ke terminal perangkat yang salah.
2. **Dynamic Argument Insertion pada Command Hub**: Nilai Interface, ONU, dan SN yang diketik pada form langsung terefleksi secara real-time ke dalam parameter CLI Command Hub dengan indikator status kelengkapan target yang presisi.
3. **Deteksi Stale Output yang Protektif**: Indikator peringatan amber "Input berubah. Generate ulang" dan penonaktifan tombol COPY saat data berubah secara aktif mencegah copy-paste skrip yang sudah usang.

## Priority Issues

### [P1] Breakpoint Layout Kaku (1280px) Memaksa Mode Accordion Mobile pada Laptop
- **Why it matters**: Di lingkungan NOC, teknisi sering menggunakan laptop (1366x768 atau 1080p dengan display scaling Windows 125% yang menghasilkan viewport efektif ~1100–1200px) atau membuka browser secara split-screen. Breakpoint `xl` (1280px) menyebabkan UI langsung runtuh ke satu kolom vertikal panjang dengan Command Hub terlipat di bawah accordion mobile.
- **Fix**: Aktifkan layout multi-kolom mulai dari breakpoint `lg` (1024px) dengan penyesuaian lebar sidebar (`w-72` atau `w-80`) agar teknisi laptop tetap mendapatkan akses berdampingan antara Form, Output, dan Command Hub.
- **Suggested command**: `$impeccable adapt`

### [P1] Ikon Centang Hijau Prematur pada Panel Output Kosong
- **Why it matters**: Panel skrip menampilkan ikon `CheckCircle2` berwarna hijau terang (`text-upaz-green`) bahkan saat form baru dibuka dan belum digenerate. Bagi teknisi NOC, centang hijau adalah sinyal universal "sudah siap / terverifikasi", sehingga menimbulkan ambiguitas status sistem.
- **Fix**: Gunakan ikon netral (misal `Terminal` atau `FileCode` warna `panel-on-navy/40`) pada kondisi kosong/belum digenerate, dan hanya ubah menjadi `CheckCircle2` hijau setelah tombol Generate berhasil dieksekusi.
- **Suggested command**: `$impeccable clarify`

### [P1] Daftar Command Hub Sepanjang 10–15 Baris Tanpa Pengelompokan & Scroll Tersembunyi
- **Why it matters**: Pada mode C300/C320, terdapat 15 baris perintah dalam satu kontainer vertikal dengan `no-scrollbar`. Teknisi yang sedang menerima komplain pelanggan harus membaca satu per satu tanpa kategori dan tidak menyadari ada perintah terpotong di bawah batas scroll 560px.
- **Fix**: Kelompokkan perintah ke dalam 3 sub-grup tematik (misal: "Monitoring & Redaman", "Tindakan / Reboot", "Status & WAN") dengan sub-label minimalis dan kembalikan indikator scrollbar tipis yang estetik.
- **Suggested command**: `$impeccable distill`

### [P2] Tab Mobile Rawan Terpotong Tanpa Indikator Horizontal Scroll
- **Why it matters**: Terdapat 6 pilihan tab konfigurasi. Pada layar smartphone (<400px), lebar total tombol melampaui layar. Kelas `no-scrollbar` tanpa efek fade/gradien tepi membuat teknisi mobile tidak mengetahui bahwa tab "UGR" dan "UCD" dapat digeser ke kanan.
- **Fix**: Tambahkan mask gradien di sisi kanan atau indikator panah halus, serta pastikan `whitespace-nowrap shrink-0` agar label tab tidak patah baris.
- **Suggested command**: `$impeccable adapt`

### [P2] Ambiguitas Bahasa dan Asimetri Hierarki Bagian Form
- **Why it matters**: Judul aplikasi menggunakan bahasa Inggris campur ("CONFIGURASI" dengan C, "Helpdesk Tool - Script Generator"), tombol utama "Generate Script", namun form bertuliskan "Tipe Konfigurasi", "Paket Layanan", dan modal "Buka/Tutup". Selain itu, field OLT tidak memiliki judul seksi (langsung muncul input), sedangkan field Pelanggan memiliki garis pemisah dan judul tebal.
- **Fix**: Standardisasi bahasa: gunakan ejaan baku Bahasa Indonesia untuk label antarmuka ("KONFIGURASI GPON UPAZNET", "Buat Skrip / Generate Skrip", "Parameter OLT"), pertahankan istilah teknis baku industri untuk nama perintah, dan berikan header seksi yang simetris untuk seksi OLT.
- **Suggested command**: `$impeccable clarify`

## Persona Red Flags

### Alex (Power User / Tier-2 NOC Engineer)
- **Red Flag 1**: Tidak ada pintasan keyboard (`Ctrl+Enter` untuk generate, `Ctrl+Shift+C` untuk copy skrip). Setiap tindakan mengharuskan perpindahan tangan ke mouse.
- **Red Flag 2**: Tidak ada tombol "Reset / Form Baru". Setelah selesai mengaktivasi satu pelanggan, Alex harus menghapus manual ID Pelanggan, Nama, SN, dan ONU ID satu per satu sebelum memasukkan data tiket berikutnya.

### Jordan (First-Timer / Junior Helpdesk Staff)
- **Red Flag 1**: Saat pertama kali membuka aplikasi, panel output sudah bertanda centang hijau. Jordan sempat mengira skrip default sudah siap pakai untuk disalin.
- **Red Flag 2**: Dropdown preset konfigurasi (UNR V130, RJW V1001, DDR Prisma) tidak memiliki petunjuk/tooltip singkat mengenai kapan opsi tersebut harus digunakan, memaksa Jordan bertanya ke senior.

### Casey (Mobile Technician on Field Support)
- **Red Flag 1**: Tab tipe konfigurasi di bagian atas tidak memperlihatkan opsi ujung kanan (UCD/UGR) karena tidak ada indikator visual bahwa baris tab dapat digeser mendatar.
- **Red Flag 2**: Tombol toggle "BUKA / TUTUP" Command Hub pada mode mobile terletak di header dengan ukuran relatif kecil berdampingan dengan switch C600/C300, rawan salah sentuh di lapangan.

## Minor Observations
- Terdapat penggunaan inline `scale-90` pada pemilih mode OLT di header Command Hub yang menimbulkan sedikit blur pada layar monitor non-HiDPI.
- Validasi field form menampilkan teks error berukuran 11px yang menyimpang dari skala tipografi 10px / 12px di `DESIGN.md`.
- Feedback salin pada panel skrip utama hanya berupa teks putih "COPIED!", berbeda dengan Command Hub yang memiliki animasi denyut hijau dan border highlight.
- Form menggunakan atribut native `required` yang memunculkan balon tooltip bawaan browser sebelum validasi pesan merah kustom dieksekusi.
